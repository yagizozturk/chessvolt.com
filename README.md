# ChessVolt — Chess Training Platform

[ChessVolt](https://www.chessvolt.com) is an interactive chess learning, training, and practice platform for children, teenagers, adults, and developing chess players. It combines structured chess openings and variations, puzzles, historical games, analysis of users real games in chess.com and lichess.org (which shows blunders and mistakes and guides for the correct moves), and guided learning experiences with an AI-powered chess coach called Volt Coach. ChessVolt is designed to help players understand chess ideas, not merely memorize moves.
Understand Why. Practice. Improve. Volt Coach is ChessVolt's virtual chess coach and provides vocal, written, and visual coaching. It provides instructional guidance intended to help players understand why a move is strong, what strategic or tactical idea is involved, and how the position should be approached. The Volt Tracker system tracks the Volts that represent progress.

## Features

- Learn and review chess openings
- Solve puzzles and practice tactical themes
- Study famous games and curated materials
- Analyze your chess.com and lichess.org games, see your blunders and mistakes, understand "why"s, develop by practicing your mistakes
- Build studies and reinforce your knowledge with spaced repetition, keep track of your progress

## Development

ChessVolt is built with [Next.js](https://nextjs.org), React, TypeScript, and
Tailwind CSS.

To run the project locally:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
